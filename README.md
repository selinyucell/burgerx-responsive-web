# Burger X

A responsive burger menu website built using HTML, CSS, and JavaScript.

## Features

- Responsive design for different screen sizes
- Hamburger menu
- Burger product cards with price information

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

After downloading the project, open the `index.html` file in your browser.

> The "Order Now" buttons are currently for design purposes only and do not process orders.
